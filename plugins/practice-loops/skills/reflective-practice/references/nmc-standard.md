# Reflective Practice — the standard ("what good looks like")

## NMC Code (four themes)
- Prioritise people · Practise effectively · Preserve safety · Promote professionalism and trust.
- A good reflective account connects the experience to one or more of these themes.

## Reflective model
- Use a recognised structure (e.g., Gibbs: description → feelings → evaluation → analysis →
  conclusion → action plan) as a scaffold; the registrant supplies the substance.

## Authenticity & ownership
- The account must be the registrant's own reflection in their own words. The loop provides a
  scaffold and prompts, not a finished narrative.

## Boundaries (the scaffold must NOT do)
- Fabricate events, feelings, or learning.
- Judge another person's conduct or fitness.
- Include identifiable patient/colleague data.
