# Policy to Practice — the standard ("what good looks like")

## Faithfulness to source
- Represent the policy/report accurately; quote or cite specific sections for each action.
- Distinguish what the source says from local inference about applicability.

## Auditable action format
- Action | Possible owner (role or TBC) | Source reference | For human decision.
- Never invent owners or deadlines.

## Governance & accountability
- Actions are candidates for the relevant governance forum to decide — not commitments.
- Flag patient-safety, regulatory, or major-resource implications for formal governance.

## NMC Code / professionalism
- Support safe, evidence-based practice and timely action on relevant guidance.

## Boundaries (the output must NOT do)
- Commit the organisation to actions or assert local applicability as fact.
- Misrepresent or overstate the source.
- Include identifiable data.
