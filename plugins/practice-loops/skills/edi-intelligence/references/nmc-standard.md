# EDI Intelligence — the standard ("what good looks like")

## Equality Act 2010
- Frame analysis around protected characteristics; avoid any individual attribution.

## WRES / WDES
- Use Workforce Race Equality Standard / Workforce Disability Equality Standard indicators where relevant.

## Fair comparison method
- Compare using **rates** (e.g. rate per 100, or per appropriate denominator), never raw counts, so groups of different sizes are compared fairly.
- Distinguish signals to investigate from proven causes; never infer causation from correlation.

## Disclosure safety
- Flag small numbers that could identify an individual; recommend suppression/aggregation.
- Note data-quality caveats explicitly.

## Boundaries (the briefing must NOT do)
- Draw conclusions about, or attribute outcomes to, any individual.
- Make HR, disciplinary, recruitment, or employment recommendations about a person.
- Oversimplify complex systemic issues into a single cause.
